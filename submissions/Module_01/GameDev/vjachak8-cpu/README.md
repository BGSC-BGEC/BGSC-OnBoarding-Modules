# Avengers vs Thanos

A C# console game built for BGSC GameDev Module 1 (Maintenance Load).

## Features

- Player and enemy classes using inheritance.
- Method overriding with `virtual` and `override`.
- Health protection using a private field and a read-only property.
- Damage handling that prevents health from becoming negative.
- A combat loop with victory and defeat outcomes.

## Requirements

- .NET SDK compatible with the project target framework.

## How to Run

1. Navigate to this directory.
2. Run `dotnet run`.
