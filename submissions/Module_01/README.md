Place your **Module 1** deliverable inside your track subfolder using your GitHub handle:

- **AppDev Track:** `submissions/Module_01/AppDev/<your-github-handle>/`
- **GameDev Track:** `submissions/Module_01/GameDev/<your-github-handle>/`

## PR Naming Convention for Module 1

- **Branch Name:** `feat/module-01-<your-github-handle>`
- **Deadline 1 (Draft/WIP PR):** `[WIP][Module 1 - D1] <Track>: <Your Name>`
- **Deadline 2 (Ready for Review PR):** `[READY][Module 1 - D2] <Track>: <Your Name>`
